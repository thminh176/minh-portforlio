Remaining existing paths were observed in this checkout. Before dispatch, coordinator confirms current paths/base and exact file list; a changed requirement needs a narrower revised scope, never an implicit wildcard expansion. Only listed paths may change. Evidence/logs/screenshots belong externally under `C:/Projects/dtm-portforlio/docs/evidence/<task>/` unless a row explicitly permits a tracked report. No full app build is required for M01.

Shared locks: route modules, layout, globals, i18n, config, manifests/lockfiles, Next config, scripts and CI have one writer at a time. UI templates never fetch content or edit adapter/schema. Codex first establishes typed route wiring; Antigravity then attaches templates without changing that wiring. Protected in every row: contact handler/form/config, `_routes.json`, provider credentials, security semantics, existing owner untracked documents and unrelated application files. Manifest/lock/Next config changes are not implicitly authorized.
